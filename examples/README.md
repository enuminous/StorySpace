# Examples are simulated, not observations

The app deliberately starts with **zero human experience records**. Its delayed-choice sorting chamber generates 2,520 deterministic synthetic values (21 spatial bins × 120 events per bin), with preassigned group labels, solely to illustrate how conditioning can reveal patterns without changing an earlier aggregate.

No synthetic example should be imported into a real analysis as a participant's prediction or real quantum experimental data.

A real externally checkable forecast record would require a concrete event, cutoff, probability, independent event adjudicator, a timestamp outside the participant's control and an approved prospective comparator. See [SS-001](../protocols/SS-001.md).

**SIMULATED ≠ OBSERVED. UNRESOLVED ≠ ANOMALOUS.**
