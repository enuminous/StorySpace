# Contributing to StorySpace

We welcome precise, falsifiable, evidence-bounded suggestions, especially adversarial analyses that find gaps in the current implementation.

## Rules

- Do not silently change frozen experimental plans or previous data. Use a versioned protocol amendment.
- Separate self-reports, interpretation, software simulation, source derivation, verified observation, and independent replication.
- Never present no-signaling-compatible delayed-choice correlations as proof of controllable backwards communication.
- Never turn the Brier loss of a single forecast into evidence of retrocausality.
- Commit a test for every claimed new engine property; document failures and missing research prerequisites.
- Do not add individual health details or other private information to this public repository without explicit permission.
- Be mindful that the research corpus includes personal experiences, which should be treated with dignity, not ridicule.

## Test locally

~~~sh
node --test tests/core.test.cjs
node --check src/core.js
node --check src/app.js
~~~

A pull request should name the exact observation that could fail, and state if it is a **hypothesis**, **software control**, **mathematical derivation**, or **physical observation**.

**The Zoo abides. The explanation may be wrong.**
