# SS-001 — StorySpace Prospective Predictions and Story/Sensation Separation

**Date:** 2026-11-09 · **Status:** PROPOSED, UNEXECUTED

## Research question

Can reports of exceptional familiarity, déjà vu, or apparent premonition predict *prospectively and specifically defined* binary events better than independently specified ordinary predictive comparators?

**Null:** The experiences do not improve prospective predictive skill beyond the allowed conventional baselines in the defined setting. The experience can still be entirely genuine without that interpretation.

This protocol is an **initial methodological scaffold**, not an externally registered or powered confirmatory human-subjects experiment. No sample size, power calculation, independent custody provider, recruitment plan, or effect threshold has yet been approved.

## Three-field discipline

1. **SIGNAL**: record what was felt, exactly when, without attributing a physical mechanism.
2. **STORY**: record the interpretation separately (familiarity without recollection, source-monitoring mistake, intuition, coincidence, metaphysical explanation, etc.).
3. **EVIDENCE**: name a discriminating observation, time-bound definition, sources, comparison model and outcome.

## Eligibility and locks

A testable entry must specify *before* resolution: event definition, event cutoff, subjective probability from 0 to 1, unique ID, scoring conditions, baseline specification and proof of temporal priority.

The web app provides only a **local freeze**: it prevents editing in the normal UI, but **does not prove when the freeze occurred** because browsers, local storage and device clocks can be modified. For genuine priority evidence, export the record and place it in independently verifiable custody (such as a git commit on a remote host) before the event. Record the commit and externally checkable time. Edited forecasts become separately versioned amendments rather than rewriting an old forecast.

### Primary score

For a properly adjudicated binary outcome \(y_i\in\{0,1\}\), a prior forecast \(p_i\in[0,1]\) receives

\[
\mathrm{Brier}_i = (p_i - y_i)^2.
\]

Mean score across eligible predictions is the primary planned quantity; lower is better. A good score for one unusual event is not evidence of anomalous causation. Calibrated probability forecasts can be evaluated against a **prospectively fixed** baseline (such as externally derived event rates). The app's displayed constant 0.5 baseline is merely a didactic reference, **not** a proper, calibrated comparator for arbitrary outcomes.

### Needed before any confirmatory execution

Document event sampling, sample size/power, recruitment, risk, expected effect and tolerance, handling of ambiguous outcome labels, independent adjudicators, missing reports, repeated predictions, multiple comparisons, permitted model updates, and a stopping rule. Publish the exact precommitment first.

## Storyspace negative controls

- Ordinary informed forecast using public information.
- Random/no-information baseline, calibrated to event domain.
- Matched controls that did **not** have a familiarity sensation.
- Post-event retrospective narrative (recorded but never admitted as pre-event evidence).
- Shuffled outcome timestamps and negative-control event categories.
- Audit of selective recording and missed forecasts.

## PASS / FAIL / UNRESOLVED

These labels apply to precise gates (e.g., "Was forecast submitted before deadline?" or "Did the prospective loss improve over comparator?"). They **do not** establish retrocausality. A significant result would be subject to further independently replicated conventional explanations.

## Quantum-filter demonstration

The application displays a **constructed toy dataset** in which later revealing pre-existing group labels yields different subgroups while the aggregate earlier histogram stays unchanged. The toy is about conditional distributions and post-selection, **not a quantum simulation**. It cannot rule out every foundational interpretation of quantum mechanics.

## Evidence boundaries

No confirmed operational backwards-in-time communication is demonstrated here. Nonstandard interpretations of quantum time remain open foundations topics; they are not validated by anecdotal experiences. Familiarity-without-recollection is a well-studied candidate mechanism, but it does not explain every episode by fiat.
